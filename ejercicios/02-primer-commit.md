# Ejercicio 02 · Tu primer commit personal
**Requisito:** ejercicio 01. **Tiempo:** 20 minutos.

1. En main, agregá una entrada real a apuntes/bitacora.md.
2. Observá el cambio con `git diff`.
3. Ejecutá `git add apuntes/bitacora.md` y `git diff --staged`.
4. Guardá con `git commit -m "docs: registrar mi primera sesión"`.
5. Comprobá `git log --oneline -3` y `git status`.

**Éxito:** existe un nuevo commit y el árbol queda limpio.
**Pregunta:** ¿este commit ya está en GitHub? No: todavía falta push.
