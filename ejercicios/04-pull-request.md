# Ejercicio 04 · Tu primer PR
**Requisito:** ejercicio 03 y autenticación GitHub. **Tiempo:** 30 minutos.

1. En main, publicá los commits locales con `git push origin main`.
2. Sincronizá con `git pull --ff-only`.
3. Creá `practica/glosario` con `git switch -c practica/glosario`.
4. Agregá al glosario una definición propia de pull request.
5. Creá un commit y ejecutá `git push -u origin practica/glosario`.
6. En GitHub abrí un PR hacia main; completá la plantilla y revisá Files changed.
7. Fusioná el PR. Volvé localmente a main y ejecutá `git pull --ff-only`.

**Éxito:** el PR figura como fusionado y la definición aparece en tu main local.
**Evidencia:** registrá el enlace del PR en PROGRESO.md en una próxima rama.
