# Ejercicio 01 · Conocer la copia local
**Requisito:** módulo 01. **Tiempo:** 15 minutos.

1. Ejecutá `git status`, `git remote -v` y `git log --oneline -5`.
2. Abrí README.md y el panel Source Control.
3. Ubicá módulos, ejercicios y proyectos en el explorador.
4. Explicá en voz alta qué diferencia hay entre Git, GitHub y VS Code.

**Éxito:** origin apunta a adolfokeeling/git-vscode, el historial existe y podés identificar tu rama.
**Pista:** `git branch --show-current` muestra la rama actual.
