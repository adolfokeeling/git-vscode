# Git, GitHub y VS Code — Aprender haciendo

Guía práctica en español para Adolfo Keeling y cualquier persona que esté comenzando desarrollo frontend.

## Empezá aquí
1. Completá [Preparación](modulos/01-preparacion.md).
2. Cloná este repositorio siguiendo ese módulo.
3. Hacé los módulos en orden y registrá tus avances en [PROGRESO.md](PROGRESO.md).
4. Practicá sobre ramas propias; cada ejercicio indica qué resultado comprobar.

Git guarda versiones en tu computadora. GitHub aloja repositorios y permite colaborar. VS Code es el editor donde podés escribir código y trabajar con Git.

## Organización
- `modulos/`: conceptos y ejemplos.
- `ejercicios/`: instrucciones, pistas y criterios de éxito.
- `proyectos/tarjeta-personal/`: HTML y CSS para modificar.
- `apuntes/`: bitácora y glosario.
- `recursos/`: comandos y documentación oficial.
- `.github/`: plantillas para futuras prácticas de colaboración.

## Rutina recomendada
Sesiones de 30–45 minutos: leer un concepto, ejecutar comandos, comprobar el resultado y anotar lo aprendido. Repetí un ejercicio si no podés explicar qué hizo cada comando.

## Ampliar el repositorio
Agregá el siguiente módulo con un número consecutivo, creá su ejercicio y enlazalos aquí. Guardá cada nuevo proyecto en una carpeta propia.

No subás contraseñas, tokens ni datos de clientes. Revisá `git diff --staged` antes de cada commit. Consultá [CONTRIBUTING.md](CONTRIBUTING.md).
