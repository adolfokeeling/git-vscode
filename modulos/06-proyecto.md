# 06 · Un proyecto visual
**Objetivo:** aplicar el flujo de Git a HTML y CSS.

La tarjeta en [proyectos/tarjeta-personal](../proyectos/tarjeta-personal/README.md) funciona sin dependencias. Abrí index.html en el navegador; refrescá para ver cambios.

HTML estructura el contenido. CSS define su presentación. Git te permite comparar y guardar cada avance.

Trabajá en una rama, hacé al menos dos commits con propósitos distintos y publicá un PR. Antes de fusionar verificá el contenido, el enlace de contacto, la lectura en celular y el diff.

**Práctica:** [Tarjeta personal](../ejercicios/06-tarjeta-personal.md).
