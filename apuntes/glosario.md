# Glosario
| Término | Significado |
| --- | --- |
| Repositorio | Archivos de un proyecto junto con su historial de versiones. |
| Commit | Versión registrada de los cambios seleccionados. |
| Staging | Área que prepara el contenido del próximo commit. |
| Rama | Referencia que permite desarrollar una línea de cambios. |
| Merge | Integración de una rama en otra. |
| Remoto | Repositorio conectado mediante una dirección. |
| Clone | Copia local de un repositorio y su historial. |
| Push | Publicación de commits locales al remoto. |
| Pull | Obtención e integración de cambios del remoto. |
| Conflicto | Cambios que requieren una decisión manual para combinarse. |
